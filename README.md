# Hoopa-Connect

Hoopa-Connect is a community-focused web portal designed for the Hoopa Valley community. It serves as a centralized platform for residents to access local news, job opportunities, a marketplace for local goods and services, and a directory of community entities.

## Features

- **Marketplace**: Browse local listings, buy and sell goods, and find community offers.
- **Jobs**: Discover local career opportunities and view application details.
- **Directory**: Access a curated list of trusted local businesses and tribal entities.
- **News & Updates**: Stay informed about the latest community developments and announcements.
- **User Profiles**: Manage your listings and account activity.

## Technology Stack

- **Frontend**: Built with HTML5, CSS3, and vanilla JavaScript for a lightweight and responsive experience.
- **Backend/Database**: Utilizes [Supabase](https://supabase.com/) for authentication and data management.
- **Development**: Developed by DataSpark Industries (established 2023) to provide practical digital tools for local communities.

## Getting Started

As this is a static frontend application, you can run it by serving the files using any standard web server.

### Prerequisites

- A web server (e.g., Apache, Nginx, or a simple development server like `python -m http.server`).

### Installation

1. Clone this repository to your local machine:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd HOOPA-CONNECT-new-branch
   ```
3. Serve the files using your preferred web server. For example, using Python:
   ```bash
   python3 -m http.server 8000
   ```
4. Open your web browser and navigate to `http://localhost:8000`.
